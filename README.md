# Faris Izzatur Rahman — Portfolio

A personal website showcasing my professional career, research contributions, and technical work in **Bioinformatics, Clinical Genomics, Workflow Automation, and Machine Learning**.

---

## About This Repository

This repository contains the source code for my personal portfolio website. It is crafted to present my professional journey, domain expertise across 65+ bioinformatics initiatives, peer-reviewed publications, and technical training programs.

### Tech Stack
- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Platform**: Deployed on [Vercel](https://vercel.com/)
